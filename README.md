# BuySell AI Agent

Enterprise-grade AI agent for the BuySell product catalog.

## Setup

1. Copy the environment template:
   ```bash
   cp .env.example .env
   ```
2. Edit `.env` and add your OpenAI API Key.
3. Run the application using `uv`:
   ```bash
   uv run python -m buysell_agent.main
   ```
